# Import Kaggle synthetic dataset (297 candidates)

**Component**: Admin CLI

**Priority**: 🔴 P0

---

## User Story

Как пользователь WayMates, я хочу видеть карьерные пути реальных профессионалов похожих на меня, чтобы принимать обоснованные решения о переходе на основе проверенных траекторий.

---

## AS IS

Нет данных о карьерных траекториях. Система не имеет похожих профессионалов для сопоставления. Проблема холодного старта - MVP не может продемонстрировать ценность без реальных данных.

---

## TO BE

Импортировано 297 IT карьерных траекторий (3,780 контекстов, в среднем 12.73 контекстов/человек). LLM-обогащенные данные (домены выведены из названий должностей, причины переходов между контекстами). Пользователи могут находить похожих профессионалов и анализировать проверенные карьерные пути. CLI скрипт с логированием прогресса, обработкой ошибок, пакетной обработкой.
