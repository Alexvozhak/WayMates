# get_story extension (view + edit career history)

**Component**: Facade MCP, Core

**Priority**: 🟡 P1

---

## User Story

Как пользователь, завершивший сбор данных, я хочу просматривать и редактировать свою карьерную историю, чтобы исправлять опечатки, обновлять навыки или удалять неправильные контексты без повторного ввода всего через полный workflow.

---

## AS IS

Инструмент `get_story` возвращает только-чтение карьерной истории. Нет способа исправить опечатки, обновить устаревшую информацию или удалить неправильные записи. Пользователи должны перезапускать полный workflow `add_experience` для простых исправлений - тратит время и токены.

---

## TO BE

Расширенный `get_story` (чтение истории любого пользователя, явный параметр userId). Новые инструменты: `update_context(contextId, updates)`, `delete_context(contextId)`, `add_context_standalone(contextData)`. Авторизация: просмотр любой истории (публично), редактирование только своей (валидация владения). Core StoryManager получает CRUD методы. Пользователи могут легко исправлять данные без повторного запуска полного workflow.
