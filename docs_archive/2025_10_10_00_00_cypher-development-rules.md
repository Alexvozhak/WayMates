# 🎯 Cypher Development Rules

## ⚠️ КРИТИЧНО: Регенерация после изменений

**После ЛЮБЫХ изменений в файлах `.cypher` в папке `src/cypher/` ОБЯЗАТЕЛЬНО запускать:**

```bash
npm run build:cypher
```

### Почему это важно?

- Файлы `.cypher` компилируются в `generated/queries.generated.ts`
- Без регенерации изменения не попадают в код
- Тесты падают с ошибками "Variable not defined"
- Это критично для работы с Cypher блоками

### Когда запускать регенерацию?

- ✅ После изменения любого `.cypher` файла
- ✅ После добавления новых блоков
- ✅ После изменения структуры блоков
- ✅ После исправления синтаксических ошибок
- ❌ НЕ нужно после изменения только TypeScript файлов

### Workflow для работы с Cypher:

1. **Редактируешь** `.cypher` файл
2. **Запускаешь** `npm run build:cypher`
3. **Тестируешь** изменения
4. **Повторяешь** при необходимости

### Автоматизация

Можно добавить в IDE:
- File watcher для `.cypher` файлов
- Pre-commit hook для проверки регенерации
- CI проверка синхронизации

---

*Это правило должно быть в памяти каждого разработчика работающего с Cypher блоками в WayMates.*
