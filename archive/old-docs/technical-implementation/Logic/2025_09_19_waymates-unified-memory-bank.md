## 💡 ИДЕИ ДЛЯ ОБСУЖДЕНИЯ

### **1. Как автоматизировать сбор троп?**
- Решение: Пользователь в Telegram надиктовывает голосовые сообщения, мы выполняем транскрибацию с помощью AI [[memory:7851828]], затем пытаемся собрать JSON, уточняем детали, согласовываем с пользователем. Если ему ок, то вносим в БД. В течение холодного старта у него есть ещё 10 дней на редактирование, а после создания нового контекста пользователя все истории (тропы) фиксируются как есть. То есть до фиксации нового контекста история не опубликовывается и не фиксируется, можно её редактировать пока что. Дополнительно: Платформа реализована как MCP-сервер, который можно подключить локально для прямого вливания историй (без Telegram). Мы (как разработчики) можем самостоятельно добавлять автоматизированный скрабинг сайтов или импорт архивных статей/историй, если они подходят по сути (решение принимает разработчик платформы).

### **2. Градация фич по уровню данных**
**Идея:** Разделить фичи на уровни в зависимости от того, какие данные есть у пользователя.

**Мои мысли:**
- **Уровень 1:** Только профиль (контекст) → базовые рекомендации
- **Уровень 2:** + тропы → персонализированные маршруты
- **Уровень 3:** + цель → точное ведение по маршруту

**Вопросы:**
- Какие фичи доступны на каждом уровне?
- Как мотивировать пользователя добавлять больше данных?
- Нужны ли "пробные" фичи для демонстрации ценности?

**Варианты ответов:**
- **A)** Строгая градация - без данных нет фич
- **B)** Деградированные фичи - работают, но хуже
- **C)** Мотивационные фичи - показывают потенциал при добавлении данных

**Мотивационная модель (чем больше данных → тем больше плюшек):**

**Уровень 1: Только контекст**
- ✅ Оценка себя среди когорты (статистика)
- ✅ Ответы на общие вопросы по статистике
- ✅ "Кто кем стал" из твоего контекста (куда пришли)
- ✅ Тропы по саморазвитию (за пределами компании)

**Уровень 2: + Цель**
- ✅ Формирование персонального маршрута
- ✅ Поиск аватаров с похожей целью
- ✅ Прогноз времени и вероятности достижения

**Уровень 3: + Маршрут**
- ✅ Рекомендации по маршруту
- ✅ Отслеживание прогресса
- ✅ Адаптация маршрута под изменения

**Уровень 4: + Тропы (монетизация)**
- ✅ Монетизация профиля (если открыт)
- ✅ Рейтинг как рассказчика
- ✅ Доступ к премиум-фичам

**Уровень 5: + Задачи (3-осевая модель)**
- ✅ Тропы по внутреннему росту в компании
- ✅ Анализ роста по 3 осям (Breadth/Depth/Ownership)
- ✅ Детекция плато и рекомендации по преодолению
