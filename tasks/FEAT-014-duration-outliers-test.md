# Add test for extreme duration outliers (120+ months)

**Component**: Integration tests

**Priority**: 🟡 P1

---

## User Story

Как разработчик, я хочу чтобы интеграционные тесты покрывали экстремальные выбросы длительности карьеры (10+ лет на одной позиции), чтобы алгоритмы сходства траекторий корректно обрабатывали долгоработающих профессионалов.

---

## AS IS

DTW similarity тесты покрывают только типичные длительности (6-36 месяцев на позицию). Нет покрытия для экстремальных случаев: 10-летняя занятость в одной компании, 1-месячные контрактные работы, пробелы в трудоустройстве.

---

## TO BE

Новый интеграционный тест DT6: U19 с 120-месячным контекстом (10 лет), проверка что similarity траекторий корректно обрабатывает экстремальные длительности (нет переполнения, нет искусственно высоких/низких скоров), документирование ожидаемого поведения для выбросов. Покрытие граничных случаев обеспечивает устойчивость алгоритма.
