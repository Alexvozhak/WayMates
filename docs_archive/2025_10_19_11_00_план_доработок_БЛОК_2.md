#### 1.1. Создать `buildGraphResultReturn()`

**Местоположение:** После строки 88 (после `buildSearchResultReturn`)

**Функция:**
```typescript
/**
 * Graph-based формирование результата для CurrentProgressionResultSchema / TargetReverseResultSchema
 */
export function buildGraphResultReturn(
  searchScope: "all" | "filtered",
  userVar: string,
  contextVar: string,
  compatibilityScoreVar: string,
  searchConstraints: SearchConstraints,
  mode: "progression" | "reverse"
): string {
  const limit = searchConstraints.results_limit;

  // Для progression: related_context = next (будущий контекст)
  // Для reverse: related_context = previous (прошлый контекст)
  const relatedDirection = mode === "progression" ? "next_context_id" : "previous_context_id";
  const relatedLabel = mode === "progression" ? "nextContext" : "previousContext";

  return `
// === GET RELATED CONTEXT (${mode}) ===
// NOTE: previous_context_id/next_context_id are PROPERTIES, not relationships!
OPTIONAL MATCH (${relatedLabel}:Context)
WHERE ${contextVar}.${relatedDirection} IS NOT NULL
  AND ${relatedLabel}.context_id = ${contextVar}.${relatedDirection}

// === RETURN GRAPH-BASED RESULT ===
RETURN {
  user_id: ${userVar}.user_id,
  match_score: ${compatibilityScoreVar},
  user_graph: {
    user: {
      user_id: ${userVar}.user_id,
      birth_year: ${userVar}.birth_year
    },
    matched_context: properties(${contextVar}),
    related_context: CASE
      WHEN ${relatedLabel} IS NOT NULL
      THEN properties(${relatedLabel})
      ELSE null
    END
  }
} AS result
LIMIT ${limit}`.trim();
}
```

**Пояснения:**
- **ВАЖНО**: `previous_context_id`/`next_context_id` - это **PROPERTIES узла Context**, НЕ связи!
- `related_context` получается через `OPTIONAL MATCH` по значению property
- Паттерн: `MATCH (relatedContext:Context) WHERE relatedContext.context_id = ${contextVar}.${relatedDirection}`
- Если `${relatedDirection}` = `null` ИЛИ узел не найден → возвращаем `null`
- `birth_year` берём из узла User

## РИСКИ И ОГРАНИЧЕНИЯ

### Риски
1. **Temporal связи**: В БД может не быть связей `previous_context_id` / `next_context_id`
   - **Решение**: OPTIONAL MATCH → если нет связи, `related_context` = null
2. **Batching**: Пока не реализован (откладываем на БЛОК 3)
   - **Решение**: Возвращаем простые массивы `CandidateGraphResult[]`
3. **Breaking changes**: Старый код может сломаться
   - **Решение**: Обратная совместимость через опциональный параметр `mode`

### Ограничения
1. **Batching отложен**: Результаты возвращаются как плоский массив
2. **Temporal constraints отложены**: Не фильтруем по `timingDiff` (БЛОК 3)
3. **27 test.todo()**: Остаются не реализованными (на будущее)
