# Resume Upload Entry Point (PDF parser + conversational flow)

**Component**: Facade workflows

**Priority**: 🟢 P2

---

## User Story

Как новый пользователь с существующим резюме, я хочу загрузить свое PDF/DOCX резюме, чтобы WayMates автоматически извлекал мою карьерную историю вместо ручного ввода в чате.

---

## AS IS

Пользователи должны рассказывать свою карьерную историю вручную через workflow `add_experience`. Утомительно для пользователей с длинными карьерами (10+ контекстов). У пользователей уже есть резюме - почему бы не использовать их?

---

## TO BE

Точка входа загрузки резюме: принимает PDF/DOCX файлы, парсит через LLM (извлекает должности, даты, навыки, компании), конвертирует в структурированные контексты, показывает превью для подтверждения пользователем, сохраняет в Core через StoryManager. Откат на ручной workflow для сложных/неоднозначных случаев. Пользователи с резюме онбордятся в 10 раз быстрее.
