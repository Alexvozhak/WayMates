# Facade NLP Gateway (simple tools + infrastructure)

**Component**: Facade MCP

**Priority**: 🔴 P0

---

## User Story

Как пользователь LibreChat, я хочу искать карьеры и управлять своей историей через простые NLP команды, чтобы взаимодействовать с WayMates естественно, не изучая технический API.

---

## AS IS

Нет Facade слоя. Клиенты должны вызывать Core напрямую с каноническими именами и структурированными параметрами. NLP взаимодействие невозможно - пользователи должны предоставлять точные названия навыков/доменов/должностей.

---

## TO BE

Facade MCP сервер с 3 простыми инструментами: `search_careers`, `get_my_story`, `set_goal`. NLP нормализация (пользовательский текст → канонические имена) с кешом словаря (24ч). Валидация авторизации (userId из токена, SQLite `auth.db`). Клиенты получают естественно-языковой интерфейс, Core остается чистым и каноническим.
