# 🎯 WayMates Career Assistant

**Ты не первый, кто идет этим путем**

WayMates Career Assistant — это AI-платформа, которая находит людей с похожим на ваш опытом и показывает, как они достигли ваших целей.

## 🌟 Главная идея

В любой момент карьеры кажется, что ты первый сталкиваешься с такой ситуацией. На самом деле тысячи людей уже прошли похожий путь. WayMates находит этих людей и показывает их траектории.

## 🔍 Как это работает?

1. **Анализируем ваш текущий контекст** — роль, технологии, опыт, компания
2. **Находим людей в похожей ситуации** — кто был там, где вы сейчас
3. **Фильтруем по вашим целям** — кто достиг того, к чему стремитесь вы
4. **Показываем их пути** — конкретные шаги, временные рамки, решения

## 🎯 Практические сценарии

- **"Хочу стать тимлидом"** → находим мидлов, которые выросли в лидов в похожих компаниях
- **"Думаю сменить стек"** → показываем, кто успешно перешел с вашего стека на желаемый
- **"Рассматриваю переезд"** → находим тех, кто переехал из вашего города в целевой
- **"Хочу в продукт из аутсорса"** → анализируем успешные переходы с похожим бэкграундом

## 🛠 Технологии

- **AI**: Обработка карьерных историй через LangGraph + OpenRouter
- **Graph DB**: Neo4j для анализа связей между карьерными контекстами  
- **Interfaces**: Telegram-бот, Custom ChatGPT, веб-API, LibreChat
- **Infrastructure**: Railway, Docker, современный TypeScript стек

## 💡 Философия

Каждый карьерный вызов кажется уникальным, но паттерны повторяются. Вместо советов "экспертов" мы даем данные о реальных людях, которые были в вашей ситуации и достигли ваших целей.

## 🎯 Для кого?

- **Разработчики** — планирующие смену стека или карьерный рост
- **IT-специалисты** — ищущие оптимальные пути развития
- **Карьерные консультанты** — использующие данные для советов клиентам
- **HR-специалисты** — планирующие траектории развития сотрудников

## 🚦 Статус проекта

🔨 **В активной разработке** — MVP планируется к релизу в Q1 2025
