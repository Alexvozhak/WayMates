### 2. **Current Context тест: "current preset U1 on full returns 1 matches"**

**Ошибка:** `expected +0 to be 1`

**Что происходит:**
- Поиск по текущему контексту с preset `full`
- User: `usr_01HX91EZ7WTKZ70YTN4ZD4X31T`
- Ожидается 1 совпадение, получается 0

**Предположения причин:**
1. **Пользователь U1 исключен из поиска** (условие `dbUser <> $me`)
2. **Нет других пользователей** с подходящими контекстами
3. **Skills формат изменился** после рефакторинга (`s.name IN candidateContext.skills`)

**Предложения по исправлению:**
```cypher
-- Проверить есть ли кандидаты для U1:
MATCH (u:User {user_id: 'usr_01HX91EZ7WTKZ70YTN4ZD4X31T'})-[:HAS_CONTEXT]->(my:Context)
MATCH (other:User)-[:HAS_CONTEXT]->(c:Context) 
WHERE other <> u AND c.position = my.position 
RETURN count(*)
```
