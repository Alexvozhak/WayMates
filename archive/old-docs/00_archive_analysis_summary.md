# Анализ архива документации WayMates

## Обзор проекта
WayMates - система карьерного развития для IT-специалистов с поиском когорт, аватаров и троп развития.

## Структура анализа
- **Бизнесовая часть**: описание фич, пользовательских сценариев, ценностного предложения
- **Архитектурная часть**: технические решения, схемы данных, алгоритмы
- **Этап проекта**: MVP, планирование, реализация, тестирование
- **Фичи**: конкретные возможности системы
- **Полезность**: актуальность и ценность для текущего состояния проекта

## Терминология (группировка по смыслу)

### Основные сущности
- **User** - пользователь системы
- **Context** / **Career Context** - карьерный контекст/этап пользователя (одно и то же, Career Context устарел)
- **Story** / **MainStory** - история карьеры пользователя (MainStory = первая входная история по памяти)

### Поиск и матчинг
- **Cohort** - когорта похожих пользователей (когда-то были с похожим текущим контекстом)
- **Avatar** - пользователь из когорты, достигший целевого контекста
- **Trail** - тропа (проверенный путь внешнего развития навыков между контекстами)
- **Route** - маршрут (тропы аватаров для построения пути развития)

### Навыки и развитие
- **Skills** - навыки (единая система, разделение на категории SKILL_CATEGORIES)
- **Skills_hard** - устаревшее разделение, больше не используется
- **SKILL_CATEGORIES** - категории навыков: language, runtime, framework, library, database, cloud, devops, testing, competency, tool

### Технические компоненты
- **Neo4j** - графовая база данных
- **Cypher** - язык запросов к Neo4j
- **TypeBox** / **Zod** - валидация схем данных (миграция с TypeBox на Zod)
- **Scoring** - алгоритм оценки совместимости
- **MCP** - Model Context Protocol для интеграций
