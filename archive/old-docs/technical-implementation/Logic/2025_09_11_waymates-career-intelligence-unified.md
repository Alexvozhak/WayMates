## 🚀 Концептуальная основа

**WayMates Career Intelligence** представляет принципиально новый подход к карьерной аналитике, основанный на **двумерном анализе карьерного роста**:

- **🏢 Internal Growth** — развитие внутри текущей компании по 4-осевой модели

### Ключевая особенность: "Три лица анализа"
Каждый анализ показывает три ориентира:
- **Пользователь** — текущая позиция
- **Аватар** — конкретный пример для подражания 
- **Когорта** — диапазон нормы среди похожих людей

## 🏢 Internal Growth: 4-осевая модель развития

### Теоретическая основа

**Проблема традиционного подхода:** Карьерный рост измеряется только вертикально (Junior → Middle → Senior → Lead), игнорируя качественные аспекты развития.

**Решение WayMates:** 4-осевая модель, которая разделяет **индивидуальную ответственность** и **разделенную ответственность** по двум измерениям.

### Три оси развития

#### **Как мы анализируем твое развитие:**
Вместо простого "Junior → Middle → Senior", система смотрит на три **независимых** аспекта твоего роста. Можешь быть сильным в одном и слабым в другом — это нормально и помогает понять, куда двигаться дальше.

#### **Ось 1: Доменная широта (Individual)**

**Простыми словами:** Сколько разных областей ты освоил в компании. Фронтенд, бэкенд, DevOps, базы данных, мобилка — чем больше, тем выше балл.

**Почему это важно:** Универсальные сотрудники ценнее — ты можешь помочь в любом проекте, заменить коллегу, быстро влиться в новую команду.
- **Критерий роста:** Решение задач в новых технических областях
- **Пример:** Фронтенд-разработчик осваивает DevOps, базы данных, мобильную разработку
- **Потолок:** Остается на текущем грейде, но становится универсальным специалистом
- **Ценность:** "Универсальный джуниор" — решает разнообразные задачи, освобождает сениоров

#### **Ось 2: Доменная глубина (Individual)** 

**Простыми словами:** Насколько сложные задачи ты решаешь в своей основной области. Если ты фронтенд-разработчик, то это переход от простых форм к архитектуре приложений.

**Почему это важно:** Глубокие эксперты нужны для сложных проектов. Плюс именно глубина влияет на твой грейд — Middle становится Senior через решение Senior-задач.

- **Критерий роста:** Решение задач выше текущего грейда
- **Пример:** Middle-разработчик решает архитектурные задачи Senior-уровня
- **Потолок:** Рост до Senior без управления людьми
- **Ценность:** Технический эксперт, решает критически важные задачи

#### **Ось 3: Неформальное лидерство (Shared)**

**Простыми словами:** Насколько ты помогаешь коллегам без официальных обязательств. Объясняешь новичкам код, проводишь митапы, заменяешь заболевшего коллегу.

**Почему это важно:** Команды растут за счет взаимопомощи. Если ты хорошо объясняешь и помогаешь — тебя заметят для Tech Lead роли.

- **Критерий роста:** Помощь коллегам, менторинг, knowledge sharing
- **Градация:** Быстрый ответ (1x) → Обучение процессу (2x) → Постоянное наставничество (3x)
- **Потолок:** Tech Lead, Architect без официального менеджмента
- **Ценность:** Масштабирование команды через передачу знаний


### Динамические "призраки" — как мы сравниваем

#### **Для пользователей:**
Представь, что твой аватар — это "призрак будущего", который показывает, где ты должен быть через месяц, два, год. Но этот призрак основан на **реальных данных**, а не на выдумке.


**Логика навигации:**
1. **Активная фаза:** Следовать графику аватара, подтягивать отстающие оси
2. **Завершение пути:** Выбрать стратегию — догнать аватара, сменить работу, найти продолжение

### Алгоритм смены аватаров

#### **Триггеры смены аватара:**

1. **Пользователь опережает:** "Ты растешь быстрее аватара 3+ месяца подряд"
2. **Пользователь отстает:** "Ты отстаешь от аватара 3+ месяца, нет сезонных причин"  
3. **Пользователь просит:** "Хочу менее/более амбициозного аватара"
4. **Аватар завершился:** "Путь аватара закончен, выбери стратегию"

## 🌍 External Growth: Динамический эталон

### Что это значит для пользователя:

Вместо поиска в Google "сколько зарабатывает React разработчик" и получения устаревших общих цифр, система **в реальном времени** анализирует людей с твоим бэкграундом и показывает актуальную картину рынка. 

Представь: ты не просто "Middle разработчик", а "Middle React разработчик в стартапах с опытом 3 года" — и система находит именно таких людей и сравнивает тебя с ними, а не с абстрактной статистикой.

### Теоретическая основа

**Проблема традиционного подхода:** Статичные зарплатные таблицы и усредненные данные не учитывают персональный контекст и быстрые изменения рынка.

**Решение WayMates:** Динамический эталон, который строится заново для каждого пользователя из актуальных данных похожих профилей.

### Принципы подбора когорты

#### **Для пользователей:** Разные типы анализа = разные группы сравнения

**Ключевая разница:**
- 🏢 **Internal:** "Как развиваться в МОИХ условиях?" (15 людей из похожих компаний)
- 🌍 **External:** "Где я на РЫНКЕ труда?" (50 людей из всех типов компаний)

## 🛠 Техническая реализация

### Как система понимает твой рост:

**Для пользователей:** Каждую неделю ты рассказываешь боту в Telegram, что делал на работе. Система задает уточняющие вопросы и определяет, по какой из 4 осей ты вырос. Никаких сложных форм — просто естественный разговор.

**Важно:** Данные видишь только ты. Система не передает информацию работодателям — она работает только на твой личный рост.

## 👤 Пользовательский опыт

### Как это работает в реальной жизни:

**Простота использования:** Никаких сложных инструментов. Заходишь в Telegram раз в неделю, рассказываешь что делал — система сама все анализирует и дает конкретные советы. МБ интеграция с Jira и тд

**Конфиденциальность:** Данные только у тебя. Работодатель не видит твою аналитику. Можешь честно рассказывать о проблемах, планах смены работы, реальном положении дел.

### Научная обоснованность

- **3-осевая модель:** Основана на анализе паттернов карьерного роста в IT
- **Динамический эталон:** Использует принципы контекстуальной аналитики  
- **Avatar-driven подход:** Применяет behavioral modeling для прогнозирования
- **Статистическая валидность:** Очистка выбросов и confidence intervals


### Измеримые преимущества

- **🎯 Персонализация:** Рекомендации основаны на твоих peers, не общих статистиках
- **📊 Актуальность:** Эталоны обновляются с каждым новым пользователем
- **🔄 Адаптивность:** Советы меняются в зависимости от рыночного контекста  
- **📈 Предиктивность:** Прогнозы основаны на реальных историях успеха
- **⚡ Actionability:** Конкретные действия вместо абстрактных советов
