# FEAT-055: Demo Video для Pre-Seed

**Date:** 2025-12-30
**Status:** PENDING
**Priority:** 🔴 P0
**Component:** Marketing, Documentation

---

## Мотивация

Для привлечения первых пользователей (pre-seed) нужны demo видео, показывающие ценность WayMates. Видео решают задачу "курица-яйцо" — демонстрируют продукт без необходимости регистрации.

---

## Два видео

### Видео 1: Quick Search (3 мин)
**Фокус:** Быстрый вход, ценность за 3 минуты
**Режим:** Adhoc (без DTW)

### Видео 2: Cold Start + DTW (5 мин)
**Фокус:** DTW Spider Chart — главный wow-эффект
**Режим:** Profile (с DTW)

---

## Сценарий Видео 1: Quick Search

```
User: /start

Bot: [приветствие, объясняет два режима]

User: Привет! Я сейчас работаю senior backend разработчиком,
      пишу на питоне, fastapi использую, уже 5 лет в разработке,
      живу в Германии

Bot: [подтверждает контекст, предлагает explore или цель]

User: Ну давай глянем кто похож на меня

Bot: [показывает кандидатов + Chart]

User: О, интересно. А я вот думаю в ML перейти, можешь помочь?

Bot: [извлекает цель, показывает что понял]

User: Да, всё верно. А есть кто уже так перешёл? Хочу понять реально ли это

Bot: [показывает pathfinders — людей кто перешёл из backend в ML]
     [Chart с goal line]

User: Круто! А сохрани мне эту цель, буду отслеживать

Bot: [сохраняет, показывает pathfinders подробнее]

User: Слушай, а какие навыки им всем понадобились для перехода?

Bot: [Advisor анализирует траектории и даёт рекомендации]
```

## Сценарий Видео 2: Cold Start с CV Upload + DTW

**Фишка:** Загрузка реального PDF резюме через Telegram → автоматический парсинг → 2-3 уточнения → поиск с DTW

### Данные из резюме (Profile.pdf):

| # | Период | Компания | Позиция | Технологии |
|---|--------|----------|---------|------------|
| 1 | 2016-2023 | Research Institute | Software Engineer | C++, Qt, STM32, Android |
| 2 | 2023-2025 | DSSL | Backend Team Lead | TypeScript, NestJS |
| 3 | 2025 | Lido Finance | Technical PM | Python, TypeScript, Vyper, Go |

### Сценарий:

```
User: [отправляет Profile.pdf как attachment в Telegram]

Bot: 📄 Обрабатываю резюме...

Bot: Вот что я понял из твоего CV:

📋 3 контекста:
1. Software Engineer @ Research Institute (2016-2023)
   C++, Embedded, Qt, STM32, Android
2. Backend Team Lead @ DSSL (2023-2025)
   TypeScript, NestJS, team of 7
3. Technical Project Manager @ Lido (2025)
   Python, TypeScript, Vyper, Go, Web3

Текущие проекты: LangChain, Neo4j, GraphRAG

Подтверждаешь? Могу уточнить детали.

User: Да, но в первом месте я больше embedded делал чем Android,
      а в Lido я скорее infra engineer чем PM, можешь поправить?

Bot: [показывает изменённые контексты]

User: Да, теперь верно

Bot: ✅ Сохранено! 3 контекста, 8+ лет опыта.
     Теперь могу искать людей с похожей траекторией.
     Показать кто прошёл похожий путь?

User: Да, покажи похожих

Bot: [показывает кандидатов с DTW метриками]
     [SPIDER CHART — главный wow момент]

     🥇 Кандидат #1: идеальное совпадение (DTW: 2.71)
     - Маршрут 0.91 — embedded → backend → web3 как у тебя
     - Ритм 0.89 — такие же сроки на позициях
     - Синхронность 0.91 — 3 этапа как у тебя

     🥈 Кандидат #2: похожий путь, спринтер (DTW: 1.52)
     - Маршрут 0.87 — те же позиции
     - Ритм 0.25 — за 4 года вместо 8

     🥉 Кандидат #3: другой путь, твой темп (DTW: 1.48)
     - Маршрут 0.31 — шёл через frontend
     - Ритм 0.86 — та же скорость

User: Интересно! А что общего у всех кто перешёл в web3?

Bot: [Advisor анализирует траектории и даёт рекомендации]
```

### Технические требования:

1. **GramJS SendMedia** — отправка PDF через `Api.messages.SendMedia`
2. **Персона скрипта** — использовать твои реальные данные из CV
3. **Эталонные кандидаты** — создать 5-6 users с похожими траекториями (embedded → backend → web3)

---

## Требуемые данные для DTW демо

| User | Роль | Shape | Tempo | Align | DTW |
|------|------|-------|-------|-------|-----|
| Demo User | Кто ищет | - | - | - | - |
| Ideal Match | 🟢🟢🟢 | ~0.9 | ~0.9 | ~0.9 | ~2.7 |
| Shape Only | 🟢🔴🟠 | ~0.85 | ~0.25 | ~0.5 | ~1.6 |
| Tempo Only | 🔴🟢🟠 | ~0.3 | ~0.85 | ~0.5 | ~1.6 |
| Align Only | 🟠🔴🟢 | ~0.4 | ~0.3 | ~0.9 | ~1.6 |
| Pathfinder | 🟡🟡🟢 | ~0.7 | ~0.7 | ~0.85 | ~2.2 |

Каждый user: 3-5 контекстов + trails + feedbacks

## Acceptance Criteria
