## 🎯 Принципы архитектуры

1. **Dependency Inversion** - внешние сервисы зависят только от интерфейсов
2. **Polymorphism** - легко заменяемые компоненты
3. **DI Container** - управление зависимостями
4. **Zero Dependencies** - нет прямых зависимостей между сервисами
