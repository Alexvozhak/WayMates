# Admin Dictionary Moderation (three-tier verification)

**Component**: Admin CLI, Core

**Priority**: 🟡 P1

---

## User Story

Как администратор, я хочу проверять и одобрять новые навыки/домены/должности, извлеченные из пользовательского ввода, чтобы канонические словари оставались чистыми и высококачественными без дубликатов или мусора.

---

## AS IS

Словари принимают любые NLP-извлеченные имена без модерации. Риск: опечатки становятся каноническими ("React.js" vs "ReactJS"), мусорные записи ("asdfgh"), почти-дубликаты ("Backend Dev" vs "Backend Developer"), спам от недобросовестных пользователей.

---

## TO BE

Трехуровневая система словарей: PENDING (пользовательские отправки) → APPROVED (проверенные админом, канонические) → ALIASES (NLP вариации → каноническое отображение). Admin CLI инструменты: проверка pending записей, одобрение/отклонение/слияние, массовые операции. Правила авто-одобрения для высоко-уверенных совпадений. Словари остаются чистыми, пользователи свободно отправляют, админы эффективно модерируют.
