# Refactor import_story: tempId mapping + Neo4j UUID generation

**Component**: Core Manager, Schema

**Priority**: 🔴 P0

---

## User Story

Как разработчик импортирующий синтетические данные, я хочу чтобы система обрабатывала предоставленные клиентом tempIds и маппила их в генерируемые Neo4j UUID, чтобы пакетные импорты работали корректно без необходимости клиенту предгенерировать валидные UUID.

---

## AS IS

`import_story` ожидает валидные UUID от клиента. Kaggle import скрипт генерирует UUIDs v7 на стороне клиента. Жесткая связанность - клиент должен знать формат UUID, версию, логику генерации. Если Core изменит UUID стратегию, все клиенты сломаются.

---

## TO BE

`StoryManager.import_story()` принимает tempIds (клиентские плейсхолдеры типа "temp_ctx_1"). Core генерирует реальные UUID (Neo4j `randomUUID()` или UUID v7), маппит tempId→realId, возвращает маппинг клиенту. Изменение схемы: поле `tempId` в input схемах, опциональное. Клиенты отвязываются от генерации UUID, Core контролирует ID стратегию.
