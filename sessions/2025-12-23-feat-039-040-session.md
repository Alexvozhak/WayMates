## Рефлексия (сквозная)

### Как делать правильно
- **Семантические описания в промптах:** ЧТО + ПОЧЕМУ, не примеры фраз (guidelines.md §1.1)
- **Один источник правды:** buildHints() в DictionariesService, не дублировать в nodes
- **Wrapper pattern:** DictionariesService(cache) — бизнес-логика отдельно от кэширования
- **Dependency injection:** Normalizer(dictionaryCache) — минимальная зависимость
- **Полные названия:** sessionService, не session; documentaryService, не documentary
- **Константы вверху файла:** DICTIONARY_LABELS, не внутри метода
- **lint:fix часто:** Проверять после каждого логического блока изменений

### Как делать неправильно
- **Примеры фраз в промптах:** LLM начинает pattern matching вместо понимания
- **sed без проверки:** Сломал import path (normalizer.js → normalizerService.js)
- **Смешивание ответственностей:** DictionariesCache с buildHints() = неправильное имя
- **Сокращённые имена:** dicts, cache, documentary — неявно, сложнее читать
- **Хардкод плюрализации:** `type + "S"` → INDUSTRYS вместо INDUSTRIES

### Инсайты

1. **Wrapper pattern для separation of concerns:**
   - Cache = Redis operations (низкоуровневый)
   - Service = бизнес-логика (buildHints, форматирование)
   - Consumer выбирает нужный уровень абстракции

2. **Dependency injection через конструктор:**
   - Normalizer(dictionaryCache) — не знает о DictionariesService
   - Тестировать проще — можно мокать только нужное

3. **Naming consistency:**
   - `*Service` suffix для классов с бизнес-логикой
   - `*Cache` suffix для низкоуровневого кэширования
   - Полные имена переменных = self-documenting code

4. **sed опасен для массовых замен:**
   - Может сломать import paths
   - Может заменить внутри строк/комментариев
   - Лучше использовать replace_all в Edit tool

### Наставления от пользователя

1. **"Промпты не должны быть забиты гвоздями"** → Семантические описания
2. **"maxSkills = 50 не то место для констант"** → Вынести в config
3. **"INDUSTRYS меня смущает"** → Explicit mapping вместо `type + "S"`
4. **"Из класса вверх файла вынести"** → DICTIONARY_LABELS как module-level const
5. **"Normalizer может принимать dictionaryCache?"** → Да, минимальная зависимость
6. **"Называй полно"** → sessionService, normalizerService, dictionariesService
