# Задача: Второя миграция схемы WayMates контекстов

## Цель
Переструктурировать JSON контексты согласно новой архитектуре.

## Преобразования:

### Группировка полей:
```json
// БЫЛО:
{
  "user_work_type": "hybrid",
  "user_work_schedule": "full-time", 
  "user_team_size": 12,
  "user_company_stage": "enterprise"
}

// СТАЛО:
{
  "work_conditions": {
    "work_type": "hybrid",
    "schedule": "full-time",
    "team_size": 12
  }
}
```

### Обновление company:
```json
// БЫЛО:
{
  "company": {
    "size": "large",
    "industry": "fintech", 
    "joined_at": "2023-12"
  }
}

// СТАЛО: (убрать stage, оставить как есть)
{
  "company": {
    "size": "large", 
    "industry": "fintech",
    "joined_at": "2023-12"
  }
}
```

### Переименование полей:
```json
// БЫЛО:
"domains_covered": ["Backend", "Architecture"]

// СТАЛО: 
"domains": ["Backend", "Architecture"]
```

### Обязательные поля (валидация):
- `role` - должен быть строкой
- `domains` - массив минимум с 1 элементом  
- `skills` - массив минимум с 1 элементом
- `role_started_at` - должен быть строкой
- `context_id` - должен быть строкой

### Правила обработки:
1. Удалить `user_company_stage` полностью
2. Переместить `user_work_*` в `work_conditions.*`
3. Переименовать `domains_covered` → `domains`
4. **Поле `skills` уже структурированное - оставить КАК ЕСТЬ!**
5. Все остальные поля оставить как есть
6. Если обязательные поля отсутствуют - пропустить файл с ошибкой

## Обработать все файлы в `/data/contexts/generated/*.json` кроме `/queries/`
