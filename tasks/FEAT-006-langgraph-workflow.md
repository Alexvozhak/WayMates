# LangGraph Data Ingestion Workflow

**Component**: Facade workflows

**Priority**: 🔴 P0

---

## User Story

Как новый пользователь, я хочу рассказать свою карьерную историю в разговорной форме, чтобы система извлекала мой опыт, не заставляя заполнять структурированные формы или предоставлять точные названия полей.

---

## AS IS

Нет workflow для сбора данных. Пользователи должны предоставлять структурированный JSON с каноническими именами в Core. Нет многоходовой беседы, нет NLP извлечения, нет управляемого сбора опыта.

---

## TO BE

Stateful многоходовой LangGraph workflow для сбора карьерных данных. MCP инструмент `add_experience(message, thread_id?)`. Workflow: Извлечение контекстов → Подтверждение → Извлечение переходов → Связывание trail → Сохранение в Core. SQLite `workflows.db` для сохранения состояния. Естественно-языковой ввод, управляемые подсказки, извлечение сущностей через LLM.
